# Blazor App Template

Use this template for Blazor applications (SSR or WebAssembly).

**Best fit:**
- Internal tools or dashboards with rich interactivity
- Teams comfortable with C# on both frontend and backend
- SSR (Server-Side Rendering) for SEO-critical pages
- WASM for offline-capable or high-interactivity experiences

**How to use:**
Copy `CLAUDE.md` to your Blazor project root.
