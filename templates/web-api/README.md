# Web API Template

Use this template for REST APIs built with ASP.NET Core minimal APIs.

**Best fit:**
- New greenfield REST API
- CRUD-heavy feature set
- Small to medium team
- No complex domain logic requiring DDD

**Stack assumptions:**
- .NET 9 or 10
- Minimal APIs (not MVC controllers)
- EF Core for data access
- FluentValidation for input validation
- Vertical Slice Architecture (feature folders) by default

**How to use:**
Copy `CLAUDE.md` to your project root before starting work with Claude Code.
